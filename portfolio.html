PROYECTO DESTACADO

Unknown Wax — sitio de marca + catálogo + reservas

Sello independiente de house y minimal en Ecuador. Necesitaba presencia web, catálogo de camisetas de tiraje limitado y un flujo de reserva simple sin backend.

Problema

  • Marca emergente sin sitio propio
  • Ventas y reservas gestionadas manualmente por Instagram
  • Catálogo que debía crecer sin complicar el mantenimiento
  • Presupuesto y tiempo limitados — MVP funcional primero

Solución

  • Sitio estático con identidad visual propia
  • Catálogo data-driven editable en js/data.js
  • Carrito de reservas con confirmación por Instagram
  • Hero interactivo con Three.js y animación de vinilo
  • Deploy automático con GitHub + Netlify
HTML CSS JavaScript Three.js Netlify

CÓMO USÉ IA

Proceso de construcción con Cursor

La IA aceleró la ejecución. Mi aporte estuvo en definir el problema, revisar cada output y validar que el producto funcionara para usuarios reales.

  1. 01

    Definir el objetivo

    Marca + catálogo + reservas por Instagram. Sin backend, sin framework pesado, fácil de mantener.

  2. 02

    Generar estructura base

    Con Cursor: layout, tokens CSS, módulos JS separados (cart.js, ui.js, data.js).

  3. 03

    Iterar por componentes

    Carrito, drawer de reservas, escena Three.js y animaciones del hero — cada uno en ciclos cortos de prompt → revisión → prueba.

  4. 04

    Revisión humana

    Validé copy de marca, flujo UX, accesibilidad (skip-link, ARIA), y comportamiento en móvil.

  5. 05

    Deploy en producción

    Push a GitHub → Netlify despliega automáticamente. Headers de seguridad configurados en netlify.toml.

Qué hizo la IA

  • Estructura HTML/CSS inicial
  • Lógica del carrito y drawer
  • Escena Three.js con prefers-reduced-motion
  • Configuración de deploy

Qué hice yo

  • Dirección de producto y tono de marca
  • Definición del flujo reserva → Instagram
  • Pruebas manuales y corrección de bugs
  • Revisión de calidad y mantenibilidad del código
“Uso IA para acelerar la construcción, pero mi valor está en definir el problema, revisar el código generado y entregar un producto que funcione en producción.”
